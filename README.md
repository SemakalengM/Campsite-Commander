# Campsite-Commander
Student no: 10520946
The purpose of the application is to allow users to:
•	Calculate the total number of items 
•	To assist users to categorise items 
•	To provide detailed checklist
•	Navigate between screens using buttons. 
•	Exit the application when required.
Pseudocode
START

Create arrays:
    days[]
    temperatures[]
    weatherConditions[]

Display Main Screen

WHEN Calculate total number of items
    total = 6

    FOR each item
        total ="1, 2, 3" 
    END FOR

    total =quantity/ number of items

    Display total number 
END WHEN

WHEN total items clicked
    Open Detailed Screen

    FOR each day
        Display shelter
        Display food
        Display safety
    END FOR
END WHEN

WHEN Exit Button Clicked
    Close Application
END WHEN
END
